AudioFileForPhone - one Windows acceptance session

1. Extract Acceptance-Kit.zip into a new folder. Keep the original ZIP beside
   that folder. Double-click Run-Windows-Acceptance.bat in the extracted folder.
   Choose the existing audio source folder in the picker. If tools are needed,
   use the normal setup selection to choose your FFmpeg bin folder once. An
   optional vendor download needs your explicit consent. No commands, PATH
   edits, administrator access or developer tools are needed.

2. Let the automatic checks finish. The kit then opens the source and prepared
   shortcut locations. Double-click "Convert selected collection" once. Press Enter
   in AudioFileForPhone to use defaults, and wait for completion. Return to the
   kit and answer its completion question. It checks the exact resulting run;
   you do not need to count files or find logs. Sources remain unchanged and
   completed collection outputs are kept for you.

3. Use the output selected by the kit on your phone: play a short section and
   seek near the end. Answer the kit's yes/no/not-tested questions from what
   you actually observed. Return only the generated REPORT.txt. Keep the local
   private evidence on this computer; do not send audio, private paths or logs.

If a check fails, stop at the specific message and return REPORT.txt if it was
created. Keep the extracted kit and its local evidence for a targeted fix.
Nothing is uploaded automatically. Unperformed observations stay NOT_TESTED.
The report identifies the exact package and actual Windows/PowerShell versions;
one computer or phone result does not establish every platform's acceptance.

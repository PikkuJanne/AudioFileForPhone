- **A20 — Deterministic collision allocation:** Stable ordinal ordering produces a repeatable source-to-output mapping even with mixed extensions, case collisions and duplicate sanitized names. Method: permuted input inventories.
- **A21 — Complete filename and path limits:** Date prefix, basename, suffix and extension budgets are enforced; long directories are rejected clearly rather than source-renamed; surrogate pairs are not split. Method: boundary unit and Windows path tests.

# T09 — Stage, validate and safely publish each output

Milestone: M2. Required.

Review improvement(s): 1. Dependencies: T08.

## Read first

STATUS.md, NEXT_SESSION.md, applicable AGENTS.md and specs/SAFETY.md, specs/PROCESS_AUDIO.md.

## Bounded work

1. Encode to a unique owned working file on the same output filesystem; it must not look like a final MP3. Explicitly specify the MP3 muxer when a .partial extension would prevent inference.
2. Check nonzero length, expected audio codec/stream, selected bitrate and plausible source/output duration with a documented empirically tested tolerance.
3. Promote to the reserved final name using no-overwrite semantics; preserve externally created destinations and handle errors as per-file failures.
4. Cover zero-exit fake success, codec mismatch, missing duration policy, corrupt/truncated output and rename/disk failures. Cleanup only owned working paths.

## Acceptance and evidence

- **A24 — Transactional success:** A final .mp3 appears only after a nonempty working file has valid expected audio, plausible duration and a no-overwrite final promotion. Method: real conversion plus staged fault injection.
- **A25 — False successes rejected:** Zero exit with empty/corrupt/non-audio/truncated/implausibly long output is failure; container bitrate including cover is not mistaken for audio bitrate. Method: stub process plus output probe fixtures.
- **A26 — Failure cleanup and destination races:** Nonzero encoder/probe/rename errors cannot leave a final-looking partial or overwrite a concurrent final file; only current owned temporary files are removed. Method: fault-injection and sentinel tests.

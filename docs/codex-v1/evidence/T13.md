Encoding requests -progress pipe:1, -stats_period 0.5 and -nostats. Parse complete
records defensively; retain one latest immutable record, lines at most 1,024 and
record at most 8,192 characters. Encoder retained stdout is 8,192; stderr remains
bounded separately. A worker observer fault disables it, preserves drainage and
bounds its diagnostic to 1,024. UI callbacks run on the PowerShell polling thread,
at most every 500 ms within a phase; mandatory phase changes bypass throttling.

Validation/promotion are distinct indeterminate stages. File success at 100 percent follows
actual publication/count; batch percent uses converted+failed with both counts.

[FFmpeg's options documentation](https://ffmpeg.org/ffmpeg.html#toc-Advanced-options)
defines machine-record boundaries and update period. Its
[progress writer](https://github.com/FFmpeg/FFmpeg/blob/master/fftools/ffmpeg.c)
emits identical microsecond values for out_time_us and historical out_time_ms,
formats arbitrary hour counts, and emits an end report on failure paths too.
The implementation treats end only as an encoding boundary.

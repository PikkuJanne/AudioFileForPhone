## Implementation and expected versus observed behavior

The explicit allowlist contains eight root files: entry PS1, functions-only
helper, BAT, README, SUPPORT, SECURITY, CHANGELOG and MIT LICENSE. The builder
requires a supplied clean detached full lowercase commit equal to HEAD, rejects
tracked/untracked/ignored dirt and required-file omissions, and refuses expansion
of this bounded distributable policy. FFmpeg/ffprobe, tests, Git metadata, logs,
media, caches, build scripts, poster and handoff evidence are excluded.

Git archive stages exact-C files and verifies each against its original Git blob,
including the builder/allowlist. Archive attributes cannot silently omit or alter
bytes. The exact functions-only helper supplies Get-AudioAppVersion; there is no
new independent build version constant. The tag must match the observed version.
ZIP members use ordinal order, fixed 1980 UTC timestamps and zero attributes.
Existing output is never overwritten; the complete three-asset directory is
published in one move after verification. Paths, reparse ancestors, staged entries
and cleanup are bounded. No downloads, Git writes or publication happen in the
builder. Source audio is never touched.

The external manifest records C, member sizes/SHA-256, ZIP bytes/SHA-256, actual
per-script Authenticode status, exact external dependency identities, build-input
digests and source/build identities. Supplied test attestations must say pass at
C with safe references and digests. **The builder validates their schema/commit;
the operator independently verifies original report bytes and results. It does
not open those referenced reports or execute their tests.** SHA256SUMS lists the
ZIP and external manifest, excluding itself. Neither manifest nor checksum is
inside the ZIP. Actual scripts are unsigned; checksums do not authenticate a
publisher. Compression/runtime differences require comparing actual bytes.

SECURITY.md documents legitimate manual external-tool sources, version/capability
queries, vendor license boundaries and exact-file trust checks. Existing local
runtime/BAT behavior, PS5.1/7, 64 kbps CBR, Music default, recursive layout,
date-first naming and metadata remain unchanged. No telemetry, production
downloader, accounts, new UI or default loudness normalization was introduced.
Workflow permissions/action pins/lock/initializer and legacy suite remain
unchanged. Routine CI adds the package harness and its source/analyzer gates.
See [package contract](../specs/RELEASE_PACKAGE.md), [source review](T19-source-review-final3.json),
[primary dependency sources](T19-dependency-sources.json) and repository SECURITY.md
